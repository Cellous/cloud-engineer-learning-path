## Choosing Firestore

This decision diagram helps identify when Firestore is a suitable database service.

Key decision factors include:

- Flexible or changing schema
- Ability to scale down to zero
- Low maintenance overhead
- Large application datasets
- Transactional consistency requirements
- Cost and size tradeoffs compared with Bigtable

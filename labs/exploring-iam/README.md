## Module Review

The Identity and Access Management module covered IAM components, identity administration, role assignment, and security best practices.

Key points:

- Corporate identities are created and administered through Google Workspace Admin or Cloud Identity.
- Identity administration may be handled separately from Google Cloud resource administration.
- Google Groups provide a useful bridge between identity management and IAM role assignment.
- IAM roles can be assigned to groups while group membership is managed independently.
- Service accounts provide workload identities and support infrastructure-level access control for applications.
